## Docker'сиз иштөө (колдонуучунун талабы)

| ТТда                 | Азыр                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| PostgreSQL Docker'до | `embedded-postgres`: чыныгы PostgreSQL 16 `node_modules` ичинен ишке кирет (5433-порт, маалымат `apps/api/.data/postgres` папкасында) |

## Кабыл алынган чечимдер (колдонуучуга айтылган)

- **Укуктар.** Матрица `packages/shared/src/permissions.ts` файлында, аны web да, API да колдонот. `OWNER` бардык админ бөлүмдөрүнө кире алат (§5: «Баары»). `FOREMAN` `/admin/orders` бетине, `ACCOUNTANT` `/admin/payroll` бетине багытталат, анткени башкы панелге кирүү укугу аларда жок. 2-этаптын бөлүмдөрү менюда «2-этап» белгиси менен боз болуп көрүнөт.
- **Tenant изоляциясы эки катмардан турат** (`apps/api/src/lib/db.ts`):
  - `tenantDb(tenantId)` ар бир суроого `tenantId` шартын кошот;
  - PostgreSQL RLS кошумча коргоо: API ээси эмес `tigu_app` ролу менен туташат жана ар бир суроо транзакциянын ичинде `app.tenant_id` коёт;
  - `systemDb()` RLS'ти айланып өтөт (`app.bypass_rls`), аны auth жана seed гана колдонот;
  - миграциялар ээси (`tigu`) катары колдонулат. Ролду түзүү жана grant'тар `apps/api/scripts/db-setup.ts` ичинде.
- **Телефон номери бүт платформа боюнча уникалдуу** (DB'деги чектөө ТТ боюнча tenant ичинде калды). Ошондуктан логин эч качан эки маанилүү болбойт. _Ачык суроо: бир тигүүчүгө эки цехте иштөө керекпи?_
- **Кызматкер кошулганда** тигүүчүгө PIN, башкаларга убактылуу сырсөз автоматтык түзүлүп, SMS/Telegram аркылуу жөнөтүлөт. Dev режиминде ал API терминалына чыгат.
- **2FA** жетекчилер үчүн демейки боюнча күйгүзүлгөн, тигүүчү менен кардарда жок. Колдонуучу формасынан өчүрсө болот.
- **«Сырсөздү унуттуңузбу?»** OTP коду менен кирүүнү ачат, анткени сырсөздү калыбына келтирүү ТТда жок.
- **`PATCH /auth/me`** endpoint'и тилди аккаунтка сактоо үчүн кошулду (ТТда endpoint көрсөтүлгөн эмес).
- **Refresh токен** ар бир колдонулганда алмашат, ал эми эски токен кайра колдонулса, бардык сессиялар жокко чыгарылат. Бир убакта ачык турган эки өтмөк же React StrictMode үчүн 10 секунддук grace period бар (`RefreshToken.rotatedAt`).
- **Кошумча таблицалар жана талаалар:** `Counter` (номерлер, §7.7), `Lead` (`POST /leads`), `Tenant.workDays`, `Tenant.shiftHours`, `Tenant.employeesCount`, `OtpCode.purpose/userId/payload`.
- **`CANCELLED` статусунун түсү** дизайнда жок, ошондуктан danger-soft колдонулду.
- **Каттоонун 3-кадамында** Excel аркылуу моделдерди гана жүктөсө болот, анткени кызматкерлерди импорттоочу endpoint ТТда жок.

## Ачык суроолор (колдонуучудан жооп күтүлөт)

1. Сайттагы тарифтердин аталыштары, баалары жана шарттары. Азыр сайтта `[БААСЫ]` жана `[ТАРИФТИН ШАРТТАРЫ]` деген белгилер турат.
2. Сайт үчүн «Биз жөнүндө» тексти жана байланыш маалыматы (`[КОМПАНИЯ ЖӨНҮНДӨ]`, `[БАЙЛАНЫШ МААЛЫМАТЫ]`).
3. Кызматкерлерди Excel'ден жүктөө үчүн `POST /users/import` кошолубу?
4. Бир телефон менен бир нече цехте иштөө керекпи?
5. Сырсөздү өзгөртүү функциясы керекпи?
6. Дизайн-холсттун скриншоттору тиркелген эмес (ТТдагы `[ШИЛТЕМЕ]` алмаштырылган эмес). Экрандар ТТдагы текст жана токендер боюнча жасалып жатат.
7. Кыргызча жана орусча тексттерди (`apps/web/src/shared/i18n/*.json`) адам текшериши керек.

## Кантип иштетүү

```bash
pnpm install
cp .env.example .env
pnpm dev                              # база + миграциялар + API (3000) + web (5173)
pnpm --filter @tigu/api db:seed       # «Демо цех»
```

**Демо-кирүү:**

- **Ээси:** телефон `555 000 001`, сырсөз `demo1234`, андан кийин 2FA коду. Код **API терминалына** чыгат: `[dev sender] ТигүүERP: кирүү коду XXXXXX`. Эң акыркы кодду алуу керек, анткени ар бир «Кирүү» басылган сайын жаңы код түзүлөт.
- **Технолог, бригадир, кесүүчү, кампачы, бухгалтер:** телефондор `002`, `003`, `004`, `006`, `007`, сырсөз `demo1234`, 2FA жок.
- **Тигүүчүлөр:** телефондор `005`, `009`, `010`, PIN `1234`.
- **Кардар:** телефон `008`, сырсөз `demo1234`.

**Пайдалуу барактар:** `/dev/ui` (бардык UI компоненттери) жана http://localhost:3000/api/docs (Swagger).

## Белгилүү тузактар (Windows жана бул компьютер)

- **Папканын аты кирилче (`тигуу`).** initdb'де `--encoding=UTF8` колдонулса, ката чыгат. Ошондуктан кластер ОС'тун коддоосу (WIN1251) менен калат, ал эми `tigu` базасы так `ENCODING 'UTF8'` менен түзүлөт (`createUtf8Database`). Бул кыргыз тамгалары (ң, ө, ү) үчүн милдеттүү. `setupDatabase` коддоо UTF8 эмес болсо, ката берет.
- **`.env` файлына `NODE_ENV` жазбоо керек:** Vite аны окуйт да, React'ты dev режиминде курат, бандл 230 КБ болуп калат.
- **Жетим процесстер.** Процесстер катуу токтотулганда postgres, API же Vite портторду (3000, 5173, 5433, 5439) кармап калышы мүмкүн, жыйынтыгында `EADDRINUSE` катасы чыгат. PowerShell'де `Get-NetTCPConnection -LocalPort 3000 -State Listen` менен таап, `Stop-Process` менен токтотуу керек.
- **Claude үчүн:** Bash'та узун heredoc (`cat <<'EOF'`) көп учурда бузулат. Файлдарды Write/Edit куралдары менен жазуу керек.
- **Тест чыгарылышын кеспөө керек:** `pnpm test` чыгарылышын `| head` менен кессе, процесс токтоп, тест postgres'и (5439) жетим калышы мүмкүн. Чыгарылышты файлга жазып, андан кийин grep кылуу керек.
- **API тесттери** `test/globalSetup.ts` аркылуу өзүнчө embedded-postgres'ти (5439-порт, убактылуу папка) ишке киргизет. Ал эми `pnpm test` пакеттерди ырааттуу иштетет (`--workspace-concurrency=1`).
- **Frontend тесттери** толук MSW handler'лерин колдонот (`apps/web/src/mocks`). Браузерде MSW бэкендде али жок endpoint'терге гана жооп берет (`browserHandlers`, азыр моделдер). Жаңы endpoint бэкендге кошулганда аны `browserHandlers`'тен алып салуу керек.

## Код эрежелери (ТТ §1, §10, §19)

- Код, комментарийлер жана аталыштар англисче. Колдонуучуга көрүнгөн тексттер `ky.json` жана `ru.json` файлдарында гана турат (API'де `apps/api/src/i18n`).
- TypeScript strict режиминде, `any` колдонулбайт. Схемалар `packages/shared` ичиндеги zod'до.
- Акча тыйын менен `Int` түрүндө сакталат (`formatMinor`/`formatMoney`, `somInputToTiyin`).
- Түстөр жана өлчөмдөр `apps/web/src/styles/index.css` ичиндеги токендерден гана алынат.
- `tenantId` сурамдан эч качан алынбайт, ал JWT'ден гана келет.
- Feature'лер бири-бирин `index.ts` аркылуу гана импорттойт. `pages` ичинде логика жок.
