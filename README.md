# ТигүүERP

Тигүү цехтери (10–200 кызматкер) үчүн ERP/MES система: буйрутма → тех. карта → кесүү жана QR-коддуу пачкалар → операцияларды сканерлөө → сдельный эмгек акы жана буйрутманын даярдыгы.

## Талаптар

- Node.js 20.11+ (`.nvmrc`)
- pnpm 9 (`corepack enable` же `npm i -g pnpm@9`)
- Docker **керек эмес**: PostgreSQL 16 `node_modules` ичинен [embedded-postgres](https://github.com/leinelissen/embedded-postgres) аркылуу ишке кирет.

## Тез баштоо

```bash
pnpm install
cp .env.example .env      # керек болсо порттарды өзгөртүңүз
pnpm dev
```

`pnpm dev` төмөнкүлөрдү бирге ишке киргизет:

| Процесс                  | Дарек                                                                      |
| ------------------------ | -------------------------------------------------------------------------- |
| PostgreSQL 16 (embedded) | `localhost:5433` (маалымат `apps/api/.data/postgres` ичинде)               |
| API (Fastify)            | http://localhost:3000 — `GET /health`, `GET /ready`                        |
| Web (Vite)               | http://localhost:5173 — `/api`, `/health`, `/ready` сурамдарын APIге берет |

Биринчи ишке киргизгенде embedded-postgres кластерди түзүп, `tigu` базасын ачат (бир нече секунд).

Текшерүү:

```bash
curl http://localhost:3000/health   # {"status":"ok"}
curl http://localhost:3000/ready    # {"status":"ok","checks":[{"name":"postgres","ok":true}]}
```

## Командалар

| Команда                             | Эмне кылат                            |
| ----------------------------------- | ------------------------------------- |
| `pnpm dev`                          | База + API + Web (иштеп чыгуу режими) |
| `pnpm db:start`                     | PostgreSQL гана                       |
| `pnpm --filter @tigu/api dev:api`   | API гана (база иштеп турса)           |
| `pnpm lint`                         | ESLint                                |
| `pnpm format` / `pnpm format:check` | Prettier                              |
| `pnpm typecheck`                    | Бардык пакеттерде `tsc`               |
| `pnpm test`                         | Бардык пакеттерде Vitest              |
| `pnpm build`                        | API (tsup) жана Web (Vite) куруу      |

## Структура

```
apps/
  api/        Fastify 4 + zod (Prisma — 2-этаптан)
  web/        React 18 + Vite (дизайн-система жана роутер — 1-этап)
packages/
  shared/     zod схемалары, enumдар, түрлөр жана таза эсептөө функциялары (web менен api үчүн жалпы)
```

## Жасалма API (MSW) жана демо-кирүү

Backend модулдары даяр болгонго чейин браузердеги API сурамдарына MSW жооп берет (`VITE_API_MOCKS=true`, `.env`). Маалымат браузердин sessionStorage'ында сакталат.

| Роль      | Телефон       | Кирүү                                   |
| --------- | ------------- | --------------------------------------- |
| Ээси      | `555 000 001` | сырсөз `demo1234`, 2FA коду `123456`    |
| Технолог  | `555 000 002` | ошондой                                 |
| Бригадир  | `555 000 003` | ошондой                                 |
| Кесүүчү   | `555 000 004` | ошондой                                 |
| Тигүүчү   | `555 000 005` | «Тигүүчү (PIN)» өтмөгү, PIN `1234`      |
| Кампачы   | `555 000 006` | сырсөз + 2FA                            |
| Бухгалтер | `555 000 007` | сырсөз + 2FA                            |
| Кардар    | `555 000 008` | «Кардар катары кирүү», сырсөз (2FA жок) |

OTP коду (каттоо, «Сырсөздү унуттуңузбу?», Telegram менен кирүү) дайыма `123456`. Код браузердин консолуна да чыгат.

Пайдалуу барактар: `/dev/ui` — бардык UI компоненттери (dev режиминде гана).

## Баштапкы ТТдан айырмасы (Docker'сиз)

| ТТда                 | Азыр                                                                 | Себеби                                                      |
| -------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------- |
| PostgreSQL Docker'до | embedded-postgres (чыныгы PostgreSQL 16)                             | Docker жок; Prisma, partial index жана RLS ТТдагыдай иштейт |
| Redis + BullMQ       | pg-boss (PostgreSQL ичиндеги кезек) — 9-этаптан                      | Өзүнчө сервис керек эмес                                    |
| MinIO (S3)           | `STORAGE_DIR` локалдуу папкасы, `StorageProvider` интерфейси аркылуу | Продакшнда S3 туташтырылат                                  |
